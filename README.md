## ما هو CRAFT WARP؟

مشروع كامل بديل عن Scratch / TurboWarp:

- **المحرك مكتوب بلغة Rust** (Axum + Tokio) — ثنائي واحد صغير، لا يحتاج تثبيت ولا Node.js.
- **المحرر يشبه سكراتش في كل شيء**: نفس الشكل، نفس الألوان، نفس طريقة سحب اللبنات، الشاشة والكائنات والمظاهر والأصوات.
- **خفيف وسريع**: لا يوجد bundler ولا أطر عمل ثقيلة. الواجهة ملفات ثابتة ~380KB فقط وتُقدَّم من داخل الثنائي (embedded).
- **يستورد ويصدّر مشاريع سكراتش `.sb3`** (المظاهر والأصوات واللبنات والمتغيرات واللبنات المخصصة) — افتح مشروعك القديم وكمّل عليه، أو صدّره وافتحه في سكراتش.
- **مكتبة جاهزة**: 18 كائنًا، 12 خلفية، 14 صوتًا — كلها مولّدة برمجيًا (SVG/WebAudio) لذلك تعمل دون إنترنت.
- **تعاون مباشر (Collab)**: اضغط زر التعاون، اختر «المضيف» فتحصل على رمز من 6 أحرف، يكتبه صديقك في «ضيف» فيدخل معك على نفس المشروع — تظهر مؤشرات أصدقائك، ومن يعدّل أي كائن، مع **دردشة مدمجة ترسل فيها الصور**.
- **زر تحميل EXE** أسفل الشاشة يجلب أحدث إصدار من صفحة الإصدارات (releases).

| | CRAFT WARP | Scratch | TurboWarp |
|---|---|---|---|
| المحرك | Rust + JS خفيف | Flash/JS | JS |
| الحجم | ثنائي واحد ~4MB + واجهة 380KB | كبير | متوسط |
| استيراد/تصدير .sb3 | ✅ | ✅ | ✅ |
| تعاون مباشر برمز | ✅ | ❌ | ❌ |
| دردشة بصور داخل المحرر | ✅ | ❌ | ❌ |
| يعمل دون إنترنت | ✅ | جزئيًا | جزئيًا |

## التشغيل السريع

### 1) من المصدر (Rust)

```bash
git clone https://github.com/ayoubkadouch82-code/craftou-warp
cd craftou-warp
cargo run --release
# افتح http://localhost:8080
```

خيارات:

```bash
craftwarp --port 9000 --host 0.0.0.0
CW_PORT=9000 CW_DATA_DIR=./data craftwarp
```

### 2) النسخة الجاهزة (exe)

من صفحة **[Releases](https://github.com/ayoubkadouch82-code/craftou-warp/releases/latest)**:

- `craftwarp-windows-x64.exe` → شغّله مباشرة (لا يحتاج تثبيت).
- `craftwarp-linux-x64` — `chmod +x` ثم تشغيل.
- `craftwarp-macos-*` للنظامين Intel و Apple Silicon.

> زر **«تحميل CRAFT WARP.exe»** في الشريط السفلي للمحرر ينقلك مباشرة إلى آخر إصدار.

### 3) للتطوير فقط (بدون Rust)

يوجد خادم معاينة مكافئ مكتوب بـ Node (نفس الـ API ونفس بروتوكول التعاون) حتى تُطوّر الواجهة دون تثبيت Rust:

```bash
npm install         # jsdom للاختبارات فقط
npm run dev         # http://localhost:8080
npm test            # اختبارات الوحدة + التعاون + الواجهة
```

> الإصدار النهائي يستخدم ثنائي Rust فقط. `devserver/server.mjs` أداة تطوير.

| التحكم | 12 | كرر، للأبد، إذا/إذا-وإلا، انتظر، حتى، انسخ/احذف النسخة، توقف |

### المحرر (يشبه سكراتش 3)
- لوحة لبنات بألوان سكراتش الرسمية + قائمة فئات جانبية.
- سحب وإفلات مع «تشبيك» ذكي (لبنة فوق لبنة، داخل C، داخل مدخل مستدير).
- تكبير/تصغير/تحريك مساحة العمل، ترتيب تلقائي، حذف بسحب اللبنة إلى سلة المهملات.
- قائمة سياق (تكرار/حذف)، تراجع/إعادة، اختصارات لوحة المفاتيح.
- تحرير المدخلات بالنقر فوقها مباشرة (أرقام/نصوص) وقوائم منسدلة ذكية (الكائنات، المظاهر، الأصوات، الرسائل، المتغيرات).
- شاشة 480×360 بمحرك رسم Canvas 2D: اتجاهات ودوران، أحجام، مؤثرات (شبح/سطوع/تدرّج)، فقاعات الكلام والتفكير، نوافذ المتغيرات.
- كائنات: إضافة من المكتبة / رسم داخل المحرر (محرر رسم مدمج) / رفع صورة / نسخ / حذف / ترتيب الطبقات.
- مظاهر وأصوات: إضافة، حذف، إعادة تسمية، معاينة، رفع ملفات.
- حفظ تلقائي محلي + حفظ على الخادم (`/api/projects`) + استيراد/تصدير JSON.
- واجهة عربية RTL افتراضيًا مع تبديل فوري للإنجليزية.

### التعاون (Collab)
- زر **تعاون** → «مضيف» أو «ضيف».
- المضيف يضغط «إنشاء جلسة» فيظهر رمز من 6 أحرف (بدون حروف متشابهة `0/O/1/I`).
- الضيف يكتب الرمز → ينضم خلال أقل من ثانية ويستلم نسخة المشروع كاملة.
- **كل تعديل يُرى مباشرة**: تحريك اللبنات، إضافة لبنات، تغيير المتغيرات، إضافة/حذف كائنات، تغيير المظاهر، تحريك الكائن على الشاشة…
- **مؤشرات الأصدقاء** تظهر فوق مساحة العمل بأسمائهم، وتظهر أيقونة صغيرة على الكائن الذي يعدّله صديقك.
- **دردشة مدمجة**: نص + صور (لصق من الحافظة أو رفع) مع عدّاد رسائل غير مقروءة.
- سجل نشاط: من انضم، من أضاف كائنًا، من أرسل رسالة.
- إعادة اتصال تلقائية عند انقطاع الشبكة، والمضيف يرسل نسخة كاملة لأي منضمّ متأخر.

### توافق سكراتش
- استيراد `.sb3` (وأيضًا ملف `.json` للمشاريع المصدرة من CRAFT WARP).
- تصدير `.sb3` يفتح في Scratch 3 وTurboWarp: `project.json` + جميع الأصول باسم `md5.ext`.
- الحفاظ على: الكائنات، المتغيرات/القوائم، الرسائل (broadcasts)، المظاهر، الأصوات، البث، اللبنات المخصصة (procedures + mutation)، الترتيب والطبقات.
- تفاصيل الفروق في [`docs/SB3-COMPATIBILITY.md`](docs/SB3-COMPATIBILITY.md).

## التعاون (Collab) — خطوات بالصور النصية

```
المضيف                                   الضيف
──────                                   ─────
تعاون → المضيف → إنشاء جلسة
   ┌──────────┐
   │  AB3X9K  │  ← انسخ الرمز وأرسله
   └──────────┘
                                          تعاون → الضيف → اكتب AB3X9K → انضم
                 ← يظهر اسم الضيف في الأعلى
                 ← مؤشر الفأرة باسمه داخل مساحة العمل
                 ← دردشة مدمجة (نص/صور)
```

- **هل يحتاج الضيف تثبيت شيء؟** لا، نفس الرابط/البرنامج.
- **هل يعمل عبر الإنترنت؟** نعم، إذا كان الخادم متاحًا (شغّل CRAFT WARP على جهاز أو استضافة). يُفضّل https لاستخدام `wss` تلقائيًا.
- **تعديلات متعارضة؟** آخر تعديل يفوز على مستوى الكائن (last-write-wins)، وهو أسلوب عملي وسريع لمشاريع اللبنات.

البروتوكول موثّق في [`docs/COLLAB.md`](docs/COLLAB.md).

## تحميل النسخة EXE

- زر التحميل الأخضر في الشريط السفلي للمحرر (`#btn-exe`) يفتح:  
  `https://github.com/ayoubkadouch82-code/craftou-warp/releases/latest`
- الإصدارات تُبنى تلقائيًا عبر GitHub Actions عند عمل tag بصيغة `v*`:

```bash
git tag v0.1.0 && git push origin v0.1.0
# .github/workflows/release.yml يبني:
#   craftwarp-windows-x64.exe
#   craftwarp-linux-x64
#   craftwarp-macos-x64 / craftwarp-macos-arm64
```

- لبناء الـ exe يدويًا على ويندوز:

```powershell
.\scripts\build.ps1
# أو
cargo build --release
# الناتج: target\release\craftwarp.exe (ثنائي واحد يحتوي كل الواجهة)
```

```
└─ .github/workflows/         # CI + إصدارات (exe لكل نظام)
```

## الاختبارات

```bash
npm install
npm test              # كل شيء
npm run test:core     # MD5/ZIP/المشروع/المفسّر/الرسم/استيراد-تصدير (17 اختبارًا)
npm run test:collab   # جلسة تعاون حقيقية بين مضيف وضيف (13 اختبارًا)
```

## English in one minute

**CRAFT WARP** is a lightweight Scratch/TurboWarp alternative: a single Rust binary (Axum) that serves a Scratch-looking block editor with 119 blocks, a full block VM (clones, custom blocks, broadcasts), `.sb3` import/export with assets, a generated sprite/backdrop/sound library, and **real-time collaboration**: one friend hosts, gets a 6-character code, the other joins with it — you both see each other's edits, cursors, selected sprite, and can chat with images. The bottom bar has a download button that points at the latest GitHub release (`craftwarp-windows-x64.exe`).

Dev quick start: `cargo run --release` (needs Rust) or `npm run dev` (Node preview server, no Rust). Tests: `npm test`.
